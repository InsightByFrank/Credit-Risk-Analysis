# 💳 Credit Risk Analysis & Explainable Machine Learning

### Machine Learning | Credit Risk | XGBoost | SHAP | Streamlit | Python

> An end to end credit risk machine learning project focused on predicting borrower default risk, understanding the drivers behind predictions, and deploying the model as an interactive Streamlit application.

---

## 🚀 Live Application

### [Launch the Credit Risk Predictor](https://credit-risk-analysis-insighbyfrank.streamlit.app/)

The deployed application allows users to enter borrower information and receive:

- Predicted probability of default
- Risk classification
- Borrower profile summary
- Model generated risk assessment
- SHAP based explanation of the prediction
- Feature contribution visualization

> **Important:** This application is an educational and portfolio demonstration. It is not intended for real world credit underwriting or lending decisions.

# 📌 Project Overview

Credit risk assessment is a classification problem where the objective is to estimate whether a borrower is likely to experience serious credit delinquency or default.

The challenge is not simply building a model that produces a high accuracy score.

A useful credit risk system should also answer:

> **Why did the model consider this borrower risky?**

This project therefore goes beyond model training.

It covers the complete machine learning workflow:
